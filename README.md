# CCNA 200-301 | Study Notes & Labs

A collection of personal notes, CLI commands, and hands-on labs created during my preparation for the **Cisco Certified Network Associate (CCNA 200-301)** certification.

I passed the CCNA exam in October 2026. This repository contains some of the resources I developed and organized throughout that journey.

## Repository Contents

| Resource | Description |
|---|---|
| [CLI Commands](commands.md) | Cisco IOS commands organized for quick reference. |
| [Networking Glossary](glossary.md) | Networking concepts, protocols, and terminology explained in Spanish. |
| [Labs](labs/) | Practical networking exercises and configurations. |

## Topics Covered

- Network fundamentals and IP addressing
- Switching, VLANs, and Spanning Tree
- Routing and OSPF
- Network services: DHCP, NAT, NTP, and DNS
- Network security: ACLs, port security, DHCP snooping, and DAI
- Wireless networking
- Network automation fundamentals

## Language

The study notes are written in **Spanish**, my native language. Cisco IOS commands, protocol names, and technical terminology are preserved in English.
